### ClanSure

**Family Insurance Management Platform**

Centralized family insurance information with policies, documents, claims, renewals, family relationships, marketplace flows and an AI assistant.

**AI:** Clara · RAG · Gemini · pgvector  
**Stack:** React · TypeScript · ASP.NET Core · PostgreSQL · FastAPI · LangChain · Redis

<a href="https://family-portal.up.railway.app/">Live system ↗</a>

### GT Companion

**Training & Knowledge Platform**

A structured training and knowledge system that brings learning resources, roadmaps, videos, quizzes and mentor content into one place.

**AI:** Pico · RAG · Gemini  
**Stack:** React · TypeScript · ASP.NET Core · PostgreSQL · FastAPI · LangChain

<a href="https://gt-companion.up.railway.app/#landing">Live system ↗</a>

### AI Agri Quality Inspection

Computer-vision driven fruit quality inspection, grading, defect analysis and profit estimation.

**Stack:** Python · Flask · TensorFlow · Keras · OpenCV · SQLite

<a href="https://github.com/imranabdul-cmd/AGRI-GRADE-AUTOMATED-QUALITY-GRADING-AND-PROFIT-ESTIMATION-SYSTEM-">Repository ↗</a>

### Lung Cancer Detection

Histopathology image classification using deep learning and image preprocessing across benign tissue, adenocarcinoma and squamous cell carcinoma classes.

**Stack:** Python · TensorFlow · Keras · OpenCV
